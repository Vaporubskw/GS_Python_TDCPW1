# SecuraPy Platform

Plataforma de monitoramento e análise de eventos de segurança (SIEM).

## Funcionalidades

- Coleta de logs de autenticação, firewall e web.
- Detecção de ataques de força bruta.
- Detecção de varredura de portas.
- Identificação de IPs presentes em blacklist.
- Armazenamento de eventos e alertas no MongoDB.
- Gerenciamento de usuários no MySQL.
- Classificação de IPs utilizando Machine Learning.
- Verificação de integridade do modelo por SHA-256.
- API REST desenvolvida com Flask.
- Dashboard para visualização dos eventos.
- Assistente de análise com IA e modo simulado.
- Containerização com Docker.

## Tecnologias

- Python
- Flask
- MongoDB
- MySQL
- Scikit-learn
- Joblib
- Docker
- OpenAI API
